First Days in Blender

Mini Project: Isometric Room

I started out following 3DGreenhorn's tutorial for making an Isometric Room. However, this was my first time really experimenting with Blender's interface and creating things on my own, so I quickly began straying from the tutorial. I imported assets from BlenderKit for the keyboard, mouse, PC, and chair, as well as certain materials such as the wood and linens but aside from that everything is my own. This project is in no way perfect, but I learned a lot about the basics of UV editing, material creation such as the transparent glass and light-emitting donut lamp, and I scraped the surface of Blender's physics features while making the curtains.

Donuts

This was my first ever project using Blender. Following Blender Guru's infamous donut tutorial, I learned the basics of the software interface, creating and modifying basic shapes, material creation, geometry nodes, lighting, and much more.
